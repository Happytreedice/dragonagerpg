[ЭТАП 1: АНАЛИЗ ИСХОДНЫХ ДАННЫХ И ПРАВИЛ (CORE RULEBOOK MD)]
--------------------------------------------------------------------------------
1.1. Выделение ключевых игровых механик Dragon Age RPG (система AGE):
     - Система 3d6 (три шестигранных кубика), где один кубик является "Драконьим" (Dragon Die).
     - Генерация Очков Приемов (Stunt Points, SP) при выпадении дублей на любых двух кубиках.
     - Основные характеристики (Abilities): Communication, Constitution, Cunning, Dexterity, Magic, Perception, Strength, Willpower.
     - Фокусировки (Foci): модификаторы +2 к проверкам характеристик.
     - Ресурсы: Здоровье (Health), Мана (Mana), Очки Опыта (XP).
     - Параметры защиты: Защита (Defense), Показатель Брони (Armor Rating), Скорость (Speed).

1.2. Анализ Markdown-файла правил для автоматического/полуавтоматического парсинга:
     - Раздел "Focuses": извлечение названий для i18n и привязка к родительским характеристикам.
     - Раздел "Talents": парсинг уровней владения (Novice, Journeyman, Master).
     - Раздел "Spells": извлечение параметров Mana Cost, Spell Type, Target Number (TN) и Test.
     - Раздел "Stunts": группировка по типам (Combat, Spell, Exploration, Roleplaying) и стоимости в SP.

--------------------------------------------------------------------------------
2.1. Создание манифеста системы (system.json):
     - Адаптация под требования архитектуры v14 (совместимость, модули данных).
     - Регистрация встроенных компендиумов (LevelDB/JSON паки) через `packFolders`.

2.2. Проектирование схемы данных (template.json):
     - Классификация сущностей типа Actor (character, npc).
     - Классификация сущностей типа Item (weapon, armor, talent, spell, focus, background, class, stunt).
     - Интеграция системных полей для хранения сносок на страницы оригинальной книги правил (например, system.source: "Core Rulebook, p. 112").


[ЭТАП 3: РАЗРАБОТКА ЯДРА ИГРОВОЙ ЛОГИКИ (DICE & RULES ROLLERS)]
--------------------------------------------------------------------------------
3.1. Реализация механики броска 3d6 с Dragon Die (JavaScript / Foundry API v14):
     - Написание класса `DragonAgeRoll` расширяющего базовый `Roll`.
     - Алгоритм: вычисление дублей среди трех кубов -> определение значения на Dragon Die -> вывод количества сгенерированных SP.
     - Поддержка модификаторов от фокусов (+2) и сторонних эффектов.

3.2. Автоматизация боевых и магических проверок:
     - Расчет попадания против статического параметра Defense цели.
     - Расчет урона оружия (например, 1d6+Strength) с автоматическим вычетом Armor Rating из итогового пула повреждений здоровья.
     - Проверки заклинаний против Target Number (TN) с генерацией Spell Stunts при дублях.
